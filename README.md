# 🛒 বাজার দর | BazarDor

**BazarDor** is a simple and user-friendly web application that helps people in Bangladesh check the prices of essential daily products. Users can explore product categories, track price changes, and compare prices across different markets.

## 🛠️ Technologies Used

* **Next.js** — React framework with App Router
* **TypeScript** — Type-safe development
* **Tailwind CSS** — Responsive and modern UI design
* **Better Auth** — User authentication
* **React Toastify** — Notifications and feedback
* **Bazar Dor API** — Product, category, and price data

## ✨ Key Features

1. **Product Price Overview:** Browse essential products with their current prices and units.
2. **Price Change Tracking:** Explore products with increasing or decreasing prices.
3. **Category-Based Browsing:** Browse products by category and sort them by price.
4. **Detailed Product Information:** View product details and market-wise prices.
5. **User Authentication:** Sign up and sign in to access protected features.

## 📱 Responsive Design

Designed to provide a user-friendly experience across mobile, tablet, and desktop devices.
